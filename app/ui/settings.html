    Details

    Projects

    A project is what you code on: a main folder, any related folders, and what the agent may do there. Chat with the built-in agent about it, or open it in OpenCode. Either way the agent is isolated from the rest of your Mac: in the macOS sandbox (works with Xcode, Swift and Homebrew), or, in OpenCode, optionally in a Linux VM that sees only the project's folders. The agent can't read your SSH keys, cloud and git credentials, keychains, browser data, shell history or other agents' sessions.

    Projects open isolated on macOS only, so far.

    Safety

    The guard looks at every command and file edit the model asks for. It blocks calls that use tools the agent was never given, reach websites nobody in the conversation mentioned, try to switch the guard off or redirect your tools, or get around network isolation. Blocked calls are replaced with a note, so nothing runs. Calls that read other agents' sessions, API keys or other processes are marked WARN and go to a second check. Each project can add sites, turn tools off and block programs (see Projects).

    Based on Hugging Face’s safeagents (github.com/huggingface/safeagents). This checks what the agent tries to do; it is not a sandbox.

    Second check for WARN calls

    A small decision model runs beside your model and scores whether each WARN call serves what you asked for. It sees your messages, the call and what the guard found, but not the agent's own reasoning, so the agent can't argue its case. It can block a WARN call, never let a blocked one through, and answers in under a second. Without it, WARN calls run and are only listed here.

    Connect a coding tool

    The built-in chat needs nothing set up. Other tools talk to the guard, which checks every tool call before it runs and forwards the rest to your local model. Opening a project in OpenCode from Projects or the menu bar sets OpenCode up for you.

    OpenCode

    Adds a “superviser” provider to your global OpenCode config and adds the loaded models, the most recently used as the default. Your other settings and comments are kept, and a backup is saved next to the file. This also happens automatically when you load a model.
