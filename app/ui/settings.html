Details

Connect a coding tool

Tools talk to the guard, which checks every tool call before it runs and forwards the rest to your local model.

Code in OpenCode (sandboxed)

Opens OpenCode for a project folder in a new Terminal window, isolated from the rest of your Mac. By default that's the macOS sandbox, which covers every command it runs and works with the Mac's own tools (Xcode, Swift, Homebrew); or, per project, a Linux VM that sees only the project folder (Apple's container tool; not for projects that need macOS tools). The first Linux VM start builds its environment once, which takes a few minutes. It can change files only in that folder (plus temporary files and build caches), and can't read your SSH keys, cloud and git credentials, keychains, browser data, shell history or other agents' sessions. API keys in your shell environment stay out too.

The sandbox is available on macOS only, so far.

OpenCode

Adds a “superviser” provider to your global OpenCode config and makes the running model the default. Your other settings and comments are kept, and a backup is saved next to the file. This also happens automatically when you start a model.

Safety

The guard looks at every command and file edit the model asks for. It blocks calls that use tools the agent was never given, reach websites nobody in the conversation mentioned, try to switch the guard off or redirect your tools, or get around network isolation. Blocked calls are replaced with a note, so nothing runs. Calls that read other agents' sessions, API keys or other processes are marked WARN and go to a second check.

Based on Hugging Face’s safeagents (github.com/huggingface/safeagents). This checks what the agent tries to do; it is not a sandbox.

Second check for WARN calls

A small decision model runs beside your model and scores whether each WARN call serves what you asked for. It sees your messages, the call and what the guard found, but not the agent's own reasoning, so the agent can't argue its case. It can block a WARN call, never let a blocked one through, and answers in under a second. Without it, WARN calls run and are only listed here.
